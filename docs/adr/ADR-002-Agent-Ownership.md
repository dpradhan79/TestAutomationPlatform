# ADR-002 Agent Ownership Model

## Status

Accepted

## Decision

Agents own:

- contracts
- prompts
- skills
- services
- tools
- tests

## Example

```text
step_generator

contracts
prompts
skills
services
tools
tests
```

## Rationale

Improves:

- Maintainability
- Discoverability
- Ownership
- Scalability
