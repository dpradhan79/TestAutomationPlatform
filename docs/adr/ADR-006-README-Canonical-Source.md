# ADR-006 README Canonical Source

## Status

Accepted

## Date

2026-08-05

## Context

Repository information can become scattered across many documents.

This increases maintenance effort.

## Decision

README.md is the primary source of truth.

## README Responsibilities

- Vision
- Architecture
- Workflow
- Agent Design
- Skill Design
- Repository Structure
- Deployment Strategy
- Roadmap

## AGENTS.md Responsibilities

- Agent contracts
- Agent responsibilities
- Delegation rules

## ADR Responsibilities

- Historical decision log

## Benefits

- Single onboarding document
- Easier maintenance
- Improved discoverability
